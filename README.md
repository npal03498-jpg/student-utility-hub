# 🎓 StudentHub

> Simple, fast and free tools made for students.

StudentHub is a lightweight, responsive web project that brings useful everyday student utilities into one place. The project is built with plain HTML, CSS and JavaScript, so it is easy to understand, modify and deploy.

## ✨ Features

- 🔢 Percentage Calculator
- 🎓 CGPA Calculator
- ⏱️ Pomodoro Timer
- 📝 Word Counter
- 🔐 Password Generator
- 📱 QR Code Generator
- 🎂 Age Calculator
- 💰 Discount Calculator
- ⚖️ BMI Calculator
- 🤖 AI Prompt Generator
- 🔎 Tool search and category filtering
- 🌙 Dark / light mode
- 📱 Responsive mobile layout
- 📖 About and Contact sections
- 🔗 Social contact links

## 🛠️ Tech Stack

- **HTML5** — semantic page structure
- **CSS3** — responsive UI, layout, themes and animations
- **Vanilla JavaScript** — tool logic and interactions
- **No framework required**
- **No build step required**

## 📁 Project Structure

```text
student-utility-hub/
├── index.html       # Main page and semantic content
├── style.css        # All visual styles and responsive rules
├── script.js        # Search, navigation, theme and tool functionality
├── robots.txt       # Search-engine crawling rules
└── README.md        # Project documentation
```

## 🚀 Run Locally

No installation is required.

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a modern browser.

For a local development server, you can also use:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
